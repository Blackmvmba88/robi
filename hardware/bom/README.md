# Ingeniería de hardware pendiente

Medir masa total y centro de masa 3D; definir radio de rueda, aceleración y pendiente. Seleccionar motores a partir de par, velocidad y corriente de arranque. Definir después driver, batería con BMS, fusibles, reguladores y paro cableado. No hay una lista de compra validada.

Los STL descargados son placas sólidas de exploración geométrica; faltan soportes, agujeros, tolerancias y análisis de carga. No son planos de ensamblaje.
